Simply Arranged

Client WorkIn Progress

  • Six-page site built on a token-based design system, where every colour, size and spacing value lives in one stylesheet and nothing else hardcodes one
  • Explicit consent gate in front of the sign-up form, so nobody submits personal data without first being told how it is handled
